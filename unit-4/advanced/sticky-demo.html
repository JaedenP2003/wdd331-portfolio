Why layout matters

Layout is the skeleton of every page. When it works, nobody notices it. When it does not, headings collide with images, buttons drift away from the text they belong to, and readers lose their place. Modern CSS gives us tools that describe relationships between elements instead of pixel positions.

The goal of this page is not to teach every tool. It is long on purpose, so there is something to scroll past while the table of contents stays put on the left.

Grid

CSS Grid lays out content in two dimensions at once. You define rows and columns, then place items into them, or let the browser place them automatically. It is the right tool when the rows and columns need to relate to each other.

Functions like repeat() and minmax() let a grid decide how many columns fit. Paired with auto-fit, a single line of CSS can replace several media queries and still behave well on a phone.

Subgrid

A grid item can be a grid itself, but by default its tracks are independent from the parent. That is why card titles, text and buttons drift out of alignment when the content differs in length.

Subgrid lets a child adopt the parent's tracks. Every card in a row then shares the same title row, body row and footer row, so everything lines up no matter how much text each card holds.

Container queries

Media queries ask how wide the screen is. A component often needs to know how wide its own space is. The same card might sit in a narrow sidebar on one page and a wide content area on another.

With container-type on a wrapper, a component can respond to the wrapper's width with an @container rule. The component becomes portable, because it no longer depends on where it is placed.

Sticky positioning

An element with position: sticky behaves like a normal element until it would scroll past an offset, such as top: 24px. From then on it holds that position inside its container. A table of contents, a section header or a sidebar are common uses.

Sticky depends on its ancestors. If a parent has overflow set to anything other than visible, that parent becomes the element's scrolling container, and the sticking happens inside it instead of in the page. The checkbox at the top of this page reproduces that bug.

Choosing a tool

Use Flexbox when items sit in one row or column and their sizes come from their content. Use Grid when rows and columns need to line up. Use subgrid when nested items must share the parent's lines. Use container queries when a component should adapt to its space, and media queries for decisions about the whole page.

Most real layouts use several of these together. The skill is picking the simplest tool that describes the relationship you want.
