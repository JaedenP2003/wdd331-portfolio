2. The core pairing

One property names the anchor, one property on the target points at that name. The target must be absolute or fixed.

4. Automatic repositioning

Drag the anchor into a corner. With fallbacks on, the tooltip flips to stay inside the box. With fallbacks off, it gets stuck on top of the anchor.

5. Pairing with the popover attribute

The popover attribute handles the top layer and light dismiss. Anchor positioning handles where it appears, and anchor-size() makes it match the button's width. Scroll so the button is near the bottom of the window and open it to see it flip upward.

6. Browser support

Anchor positioning reached Baseline in January 2026: Chrome and Edge 125+, Firefox 147+, Safari 26. Behavior around overflow and fallbacks still differs a little between browsers, so test in more than one.
