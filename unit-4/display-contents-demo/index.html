4 · Safer alternatives

.wrapper--subgrid {
  display: grid;
  grid-template-columns: subgrid;
  grid-column: 1 / -1;
}

Reasonably safe

  • A plain <div> that only groups things
  • No role, no ARIA, not interactive
  • Tested in a browser and with a screen reader

Never

  • <button>, <a>, <input>, <select>, <textarea>
  • Landmarks: <header>, <nav>, <main>, <footer>, <aside>, <section>
  • Anything with role or aria-label
