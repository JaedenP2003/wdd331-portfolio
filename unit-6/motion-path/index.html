Motion Path Demo

A glider that follows a curve, using only offset-path and offset-distance.

Motion is on. Your system has no reduced motion preference.

Reduced motion is on, so the gliders rest at their destinations.

1. Follow the path

The dashed line is the SVG path from path.svg. The glider uses the same d string in CSS.

2. The coordinate system has to match

Numbers in path() are pixels measured from the stage, not from the SVG's viewBox. Shrink the drawing without changing the CSS and the glider leaves the line.

3. Do you even need a path?

All three gliders travel from the same start to the same end.

4. Reduced motion

By default every glider sits at the end of its route, with no animation. The animations are added only inside @media (prefers-reduced-motion: no-preference). To see it, open DevTools, run "Emulate CSS prefers-reduced-motion" and choose reduce.
