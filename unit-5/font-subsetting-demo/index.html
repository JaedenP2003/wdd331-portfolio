2. Static subsetting

The files were built ahead of time with pyftsubset, part of the fonttools toolkit. Each script gets its own range of Unicode code points:

python -m fontTools.subset Inter-Variable.ttf --unicodes="U+0000-00FF,U+0131,U+0152-0153,U+2000-206F" --flavor=woff2 --output-file=Inter-latin.woff2

The same ranges go into unicode-range in after.css, so the browser only downloads the files a page needs.
