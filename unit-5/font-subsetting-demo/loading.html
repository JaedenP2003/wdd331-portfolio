What you should see

  • Block: the text is invisible while the font downloads. That is the flash of invisible text.
  • Swap: the text shows right away in a fallback serif font, then jumps to the web font when it arrives. That is the flash of unstyled text.
  • Smaller file: load the Latin subset and both windows get shorter, because the file finishes downloading sooner.
