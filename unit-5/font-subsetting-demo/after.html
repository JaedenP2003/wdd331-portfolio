Before After FOIT vs FOUT

An English page

Everything you are reading uses a small fraction of the characters inside this font. The page only needs the letters, numbers and punctuation of ordinary English, plus a few accented characters like café, résumé and naïve.

What the browser downloads

  • One font request, for the Latin subset only.
  • Greek, Cyrillic and Latin Extended files are declared, but the browser skips them because no character on the page falls in their unicode-range.
  • Same font, same look. Only the unused glyphs are gone.

Watch unicode-range work

Keep the network panel open, filtered to Font. Then add text from another script. The browser requests the matching file at that moment, and only then.
